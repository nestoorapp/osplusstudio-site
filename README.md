# osplusstudio.com

Static website of OSplusstudio and its products: Qrocket, MuslimPlus and Nestor.

| Path | Page |
|---|---|
| `/` | Studio home page |
| `/gizlilik.html` | Studio privacy policy |
| `/qrocket/` | Qrocket landing page and pilot sign-up form |
| `/muslimplus/` | MuslimPlus landing page and privacy policy |
| `/nestor/` | Nestor landing page, waitlist, privacy and support |

Plain HTML and CSS, no build step. Deploy the repository root as-is (Netlify, Cloudflare Pages or GitHub Pages).

The Qrocket pilot form and the Nestor waitlist use Netlify Forms: turn on **Forms → Form detection** in Netlify and redeploy once.
